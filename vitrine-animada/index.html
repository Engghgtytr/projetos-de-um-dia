Vitrine animada

Quatro jeitos de dar vida à foto de um produto só com CSS, sem biblioteca. Todos animam apenas transform e opacity, que o celular desenha sem travar. A marca "Lima" é fictícia.

Flutuar

O produto sobe e desce devagar, e a sombra encolhe junto. Bom para o topo de uma landing page.

Ver o código
@keyframes flutuar {
  50% { transform: translateY(-14px); }
}
.produto {
  animation: flutuar 3s ease-in-out infinite;
}

Entrar

O produto aparece subindo e crescendo um pouco, com uma curva que freia no fim. Faça a entrada uma vez, não em loop.

Ver o código
@keyframes entrar {
  from { opacity: 0; transform: translateY(24px) scale(.94); }
}
.produto {
  animation: entrar .7s cubic-bezier(.23, 1, .32, 1) both;
}

Reflexo

Uma faixa de luz atravessa o produto de tempos em tempos. Chama a atenção sem cansar.

Ver o código
@keyframes reflexo {
  0%, 60% { transform: translateX(-120%) skewX(-20deg); }
  100%    { transform: translateX(220%) skewX(-20deg); }
}
.luz { animation: reflexo 3.5s ease-in-out infinite; }

Girar em 3D

O produto vira de um lado para o outro, como numa vitrine giratória. Usa perspective no pai.

Ver o código
.palco { perspective: 600px; }
@keyframes girar {
  0%, 100% { transform: rotateY(-35deg); }
  50%      { transform: rotateY(35deg); }
}
.produto { animation: girar 4s ease-in-out infinite; }
Se o seu sistema estiver com "reduzir movimento" ligado, as animações começam pausadas. Projeto de portfólio da Penchel.Dev.
